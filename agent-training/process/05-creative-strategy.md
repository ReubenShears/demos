# 05 · Creative strategy and angle plan

## Purpose
Decide what the batch will say before anything is designed: which angles, which formats, which proof, how many ads.

## Trigger
Offer lock posted (step 02). For a later batch: a decision from step 16 (new ad set off winners, tighter ICP callout, new offer).

## Inputs
- Offer lock, Client Data row
- Previous batches for this client (Baserow Creative Batch Data, Drive folders, ad sheets)
- Performance by ad name if the client is live (Baserow Ad Data)
- Optimally's own winning statics, used as templates for clients
- Competitor ads in the client's niche

## Steps

1. **Fix the constants** for the whole ad set:
   1. One **headline** (the Meta headline under the image), shared by every ad. Pattern: `<Offer> For <ICP>`, e.g. "Pay Per Booked Job For HVAC Companies Running 3+ Trucks".
   2. One **eyebrow** (the ICP callout on the image): "FOR LOAN OFFICERS", "RESTAURANT OWNERS", "RUNNING META DM ADS?". It must be large. Repeated feedback has been to make it bigger.
   3. One **offer line**, worded exactly as in the offer lock.
2. **Choose the batch size**: 8 to 15 statics for a first ad set. Observed sets: 8, 10, 10, 11, 12, 13, 14.
3. **Pick angles**, one per ad. Draw from: offer, pain, proof or case study, enemy (the thing they hate: shared leads, retainers, agencies), reframe, contrarian, mechanism, risk reversal, curiosity, future-pace, fear, authority, price anchor, seasonal, capacity.
4. **Pick formats**, mixing them so the set does not look uniform in feed:
   - Bold statement (type only)
   - Plain offer
   - Minimal (one phrase, nothing else)
   - This vs That / Before and After
   - Fake UI: text thread, DM thread, lock-screen notifications, incoming call, calendar, dashboard
   - Stat or guarantee
   - Framework diagram (two-path flow)
   - Case study, photo-led or results grid
   - Founder-led (headshot or stage photo)
   - Listicle, lead-magnet mockup, meme-native
   - Carousel (case study, 6 cards) when there is a story to tell
5. **Apply the house rules for a set**
   1. Include at least one light ad in a dark set (or the reverse) "so it breaks the pattern in feed".
   2. Include **straight copies of proven winners and design variations of each**, so they can be compared.
   3. Include competitor-style ads in every batch.
   4. A new ad set must not cannibalise the current winner: if the winner is a text thread asking "so how do you get paid?", the new set may reuse the question but not as a text thread.
   5. The size filter belongs in the eyebrow or headline ("3+ trucks") so the wrong people scroll past.
   6. Do **not** put revenue qualifiers on the image ("$1M+ only"). It cuts lead volume and raises CPMs. Put qualifiers in the primary text.
6. **Assign proof**: for each proof ad, name the case study, the number, and whether the client may be named. Default to "one client" / "our client" unless the client has approved naming.
7. **Write the plan as a table**: Ad ID, Angle / Desire, Format, On-image headline, Proof used, Visual idea, Light or dark.
8. **Dedupe** against earlier batches: no repeated format-and-angle pair unless it is a deliberate winner variation.

## Output and handoff
- Angle plan table, one row per ad, posted in `#delivery`
- Next: step 06 (design) and step 09 (copy) work from the same table

## Rules
- Statics first. Video comes after winners are known (step 17), unless the client already has strong organic reels and is good on camera; then cut those into ads for a second ad set.
- Tightening the audience callout raises cost per booked call but improves close probability. Say so to the client when proposing it.

## Not confirmed
- A fixed ratio of angle types per batch. None is written down.
