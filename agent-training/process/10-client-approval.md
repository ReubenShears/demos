# 10 · Client creative approval

## Purpose
Get a clear written yes from the client on the ads, with every risky item confirmed explicitly, in one round where possible.

## Trigger
Batch passed QC and has its variants (steps 07 and 08).

## Steps

1. **Prepare the review folder**: a Drive folder containing only the originals the client should judge (not Reels-safe copies, not rejected versions). Share as "anyone with the link can view".
2. **Post in `<client>-main-chat`**, tagging the decision-maker. Pattern in use:

   > Hi @Client, I've attached the first set of ads for you to look through, keen to know your thoughts 👍
   > `<Drive folder link>`

   For a later batch: "I've attached the new set of ads calling out `<ICP change>`, keen to know your thoughts."
3. **Add the confirmation questions** from the QC list as bullets, under "two things to note with these ads":
   - Results: "Ads 1 and 2 use results `<name>` mentioned on the onboarding call. Can you confirm these numbers are accurate and that you're happy for us to run them? We haven't named the clients but can change that if you prefer."
   - People: "Ad 3 uses `<name>`'s headshot. Are you okay with this being in the ad?"
   - Any claim, badge, review or named client.
4. **If the plan differs from the usual**, explain it briefly. Example: "We usually don't start with video ads, but your reels would work well as ads and you're good on camera, so I've cut a few into ads."
5. **Answer design questions with the reason.** Typical ones:
   - Safe zones: "all copy needs to sit inside the centre 1:1 square of the 9:16, roughly 22% to 78% of the height. Meta crops to square in feed and covers the bottom 20-35% with its own UI in stories and reels."
   - Logos: "we need to be careful around logos as Meta usually rejects these; naming the company is fine."
   - Audience callout: "we still need the eyebrow calling out `<ICP>`; without it it's hard to tell who we're targeting."
   - Revenue tags on the image: "putting revenue tags on the ads themselves usually kills lead volume and pushes CPMs up. As spend goes up we feed Meta more pixel data, so it gets better at finding the right people. Happy to add it to the primary text."
   - Video: "for the first 7 days we monitor static performance, then make decisions about video from there."
6. **Wait for a yes.** Accept "good with it", "love it", a thumbs-up from the decision-maker. If a team member approves but the owner has not, ask the owner.
7. **If no reply in one working day**, bump the message. A bump from a second team member is normal ("just bumping the above message, then we can get live").
8. **On approval**: tell `#delivery` "`<Client>` ads approved", finalise the ad sheet (step 09), and ask for the budget if it is not set (step 12).
9. **On feedback**: go to step 11, then return here with "the `<change>` has been made on all the ads, please could you confirm you're happy to run with these?" and the new folder link.

## Output and handoff
- Written approval in the client channel, with result numbers and likenesses confirmed
- Next: step 12

## Rules
- Never launch on silence.
- Never run a result number or a person's image the client has not confirmed in writing.
- Keep the tone warm and brief. One message, one link, bullets only for questions.
- When the client's own designers made the ads, feed back in the same way: praise, then specific flags with reasons.

## Not confirmed
- Whether approval is also needed from Reuben internally before the client sees a batch. Reuben has reviewed creative before client calls for some clients; no fixed rule found.
